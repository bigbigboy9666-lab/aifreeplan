Bolt.gives 完全免费：开源 AI 编程代理平台使用攻略

2026年3月，Bolt.gives 正式推出其免费 AI 编程代理平台，这是一个基于开源架构的 AI 驱动编码工作空间。与 Replit Agent、Cursor 等付费产品不同，Bolt.gives 的核心托管服务对公众完全免费——每位用户每天享有 $1 的编程额度，足以完成中小型项目的开发和迭代。

Bolt.gives 是什么？

Bolt.gives 是一个协作式、开源的 AI 编程工作空间（collaborative, open-source AI coding workspace）。它的核心理念是让你用自然语言描述想要构建的应用，AI 代理自动生成代码并在内置的 Preview 面板中实时预览结果。

该平台基于 Cloudflare Pages 部署，使用 React + Vite 作为前端技术栈，后端运行在 Node.js + systemd 上，数据库采用 PostgreSQL。整个项目开源在 GitHub（github.com/embire2/bolt.gives），当前稳定版本为 v3.0.9.32（2026年7月1日发布）。

免费额度详解

托管版 FREE 路径

  • 每日额度：$1/人/天（per-person daily coding cap）

  • 重置时间：每天 00:00 GMT+2 自动重置

核心功能

1. AI 编程代理

在 Chat 界面中输入自然语言描述，AI 代理会自动分析需求、生成代码文件、安装依赖并启动预览。整个过程不需要手动编写任何代码。工作区分为两个主要面板：

  • Preview 面板：实时展示生成的 Web 应用
  • Code 面板：查看和编辑生成的源代码

2. 项目发布

生成的项目可以直接发布到免费的 bolt.gives 子域名，格式为 https://your-app.bolt.gives。发布流程通过 Cloudflare A 记录和 Caddy 路由自动配置 HTTPS，整个过程无需手动操作。

如果需要自定义域名，可以选择$10/月的托管服务（通过 Stripe Checkout 订阅），平台会指导你创建 A 记录指向服务器 IP。

3. 模板包（Template Packs）

Bolt.gives 内置了多种第一方模板包，帮助 AI 更快地生成符合预期的应用：

  • 日历规划器：带周视图网格、议程面板、事件创建的 React 应用
  • 仪表板：数据可视化管理面板
  • 营销站点：响应式企业官网
  • 电商目录：商品展示和购物车
  • 作品集：设计师/开发者作品展示
  • 预约调度器：带患者预约、医生选择、SMTP 提醒的完整应用

4. 协作与实时更新

平台通过 wss://bolt.gives/collab WebSocket 端点支持多人实时协作。多个开发者可以同时编辑同一个项目，Changes 会同步到所有参与者。

5. 自托管选项

由于项目完全开源，你可以选择自托管。安装脚本会自动配置应用、运行时、协作服务和网页浏览服务，并设置本地 PostgreSQL 数据库。支持 Caddy HTTPS 自动证书配置。自托管版本还内置了 /api/update 自动更新器。

技术亮点

1. 确定性首屏引导

Bolt.gives 使用确定性启动引导（deterministic starter bootstrap），防止 AI 模型在空工作区中发出无效的 shell 命令。首次运行时会先创建基础文件结构（package.json、index.html 等），然后再执行安装和构建命令，避免了常见的"先跑命令后建文件"的问题。

2. 安全壳保护

平台实现了Shell 安全守卫（shell safety guard），禁止通过终端重定向（如 echo >、cat >、tee、sed -i）直接写入项目文件。所有文件变更必须通过明确的文件操作指令（<boltAction type="file">）完成，确保代码变更的可追溯性。

3. 智能预览恢复

当预览面板因错误崩溃时，Bolt.gives 会自动尝试恢复。它会探测 Vite 入口模块图，在标记预览健康之前验证 /src/main.tsx 等关键文件是否有效，避免假阳性。

4. 自动更新系统

托管实例内置了内置 Web 应用更新器，当新版本发布时，页面顶部会出现更新横幅。用户可以选择可选更新或强制更新。更新过程会创建回滚检查点、保存本地更改到 git stash、安装依赖、构建新版本，最后安排服务重启。
