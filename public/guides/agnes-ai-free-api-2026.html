6月1号，Agnes AI干了件狠事。 文本、图片、视频三个模型的API全部免费开放，无限期，不要订阅，不要等名单。 全球第一家全模态（文本+图片+视频）同时免费的AI平台。

三个模型，三个方向

文本模型：Agnes-2.0-Flash - 上下文：256K（后来升级到1M） - 最大输出：65.5K - 擅长：多轮对话、代码生成、Agent工作流、工具调用 - 用途：聊天、写代码、做Agent规划、跑自动化流程 图片模型：Agnes-Image-2.0-Flash - 支持：文生图、图生图 - 用途：封面图、电商主图、信息图、社交媒体配图 - 速度：比大多数免费生图API都快 视频模型：Agnes-Video-2.0 - 支持：文生视频、图生视频、关键帧动画 - 特点：音画同步生成 - 注意：异步任务，先创建任务再轮询结果，高峰期要排队

怎么注册

  1. 打开 platform.agnes-ai.com
  2. 用邮箱注册账号（跟普通用户端是分开的，API平台专门给开发者用）
  3. 登录后创建API Key
  4. 复制Key，开始调用 API Key创建很简单，平台界面上有一个明显的按钮。

接入方式

文本模型走OpenAI兼容接口，几乎所有主流框架都能直接接：

Base URL: https://apihub.agnes-ai.com/v1
模型名: agnes-2.0-flash

Python示例：

from openai import OpenAI
client = OpenAI(api_key="YOUR_KEY", base_url="https://apihub.agnes-ai.com/v1")
response = client.chat.completions.create(
    model="agnes-2.0-flash",
    messages=[{"role": "user", "content": "你好"}]
)

图片模型走单独的接口：

POST https://apihub.agnes-ai.com/v1/images/generations

视频模型也是单独的异步接口：

POST https://apihub.agnes-ai.com/v1/videos/generations

先POST创建任务，拿到task_id，然后轮询结果。视频生成比较吃资源，排队是正常的。

能接入哪些工具

文本模型因为是OpenAI兼容格式，几乎所有支持自定义API的工具都能接： - Hermes Agent — 配置自定义模型提供商，填API Key、Base URL和模型名 - Claude Code / Cursor / Windsurf — 这些编程工具都支持自定义API - WorkBuddy — 可以打包成Skill，在对话里直接调用 - n8n — 通过HTTP请求节点调用 - OpenClaw — 配置为默认模型 图片模型和视频模型目前主要走API调用，或者封装成MCP工具给主模型调用。

实测效果

文本模型：写代码能力不错。让它做一个高德地图风格的App界面，或者Three.js粒子系统，都能直接出可运行的代码。复杂结构化任务的表现超出预期。 图片模型：理解Prompt的能力很强。赛博朋克雨夜东京、电商主图、信息图文案排版，都能准确还原需求。速度也快。 视频模型：15秒的龙族苏醒视频，电影级质感，鳞片细节、火焰物理、运镜节奏都有。音画同步效果也很自然。但视频生成要等，高峰期排队时间长。

注意事项

免费不代表没限制。几个需要注意的点： 1. 没有SLA保障 官方服务条款明确写了：免费计划不提供SLA，不保证服务可用性。高峰期可能遇到500、502、503错误。 2. 视频生成要排队 异步任务，创建后需要轮询。高峰期排队时间不确定，别指望即时出结果。 3. "无限期免费"不等于"永久免费" 历史上不少免费API后来都改了策略。阿里云之前的iFlow CLI也是"永久免费"后来停了。Agnes现在确实是免费的，但长期能不能撑住，要看平台策略和商业化节奏。 4. 适合做原型，不适合做生产 现阶段最适合的用法：做Demo、跑原型、批量试封面方向、给Agent接备用模型、生成内部素材。正式上线还是建议用付费方案。
