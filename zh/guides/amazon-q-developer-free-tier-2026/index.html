Amazon Q Developer 免费攻略：无限代码补全+聊天+安全扫描

AWS的Amazon Q Developer曾经是白嫖神器，但现在情况变了。

好消息是：如果你已经有账号，免费层还能用。坏消息是：2026年5月15日起，不再接受新注册。

也就是说，这个免费入口基本关上了。但如果你能通过其他方式拿到账号，免费层的福利还是很实在的。

免费层包含什么

Amazon Q Developer的免费层是永久性的，但有限额：

  • 50次Agent请求/月 — 包括Q&A聊天和Agent式编程
  • 1000行代码转换/月 — 比如Java 8升级到Java 17
  • 无限代码补全 — 在IDE里打字时的自动补全没有次数限制
  • 安全扫描 — 基础漏洞扫描免费
  • 参考追踪 — 自动标注开源代码片段来源

支持的环境：VS Code、JetBrains IDE、Visual Studio、Eclipse，以及CLI。

免费层 vs 专业版

功能 免费 专业版($19/月)
Agent请求 50次/月 1000次/月
代码转换 1000行/月 4000行/月
代码补全 无限 无限
安全扫描 基础 高级+IP赔偿
SSO集成 不支持 支持(IAM Identity Center)
管理面板 不支持 支持

如果你只是日常写代码用用，免费层的50次Agent请求+无限代码补全基本够用。但50次真的不多——一个Agent任务可能消耗几次请求。重度使用者建议上Pro。

怎么注册

重要：新注册已关闭。 2026年5月15日起，AWS停止了Amazon Q Developer的新账号注册。

如果你之前已经注册了Builder ID或通过IAM Identity Center接入，你的账号不受影响，继续正常使用。

注册方式（仅适用于已有账号的恢复或迁移场景）：

  1. 下载IDE插件（VS Code / JetBrains / Visual Studio / Eclipse）
  2. 通过AWS Builder ID登录
  3. 免费层自动启用

注意：Builder ID是个人账号系统，和AWS付费账号是分开的。免费层只支持Builder ID和IAM用户，不支持IAM Identity Center（那是Pro的功能）。

核心功能

代码补全 — 实时建议，支持多种语言。这是免费层里唯一真正“无限”的功能。打字时自动补全，不消耗任何额度。

Agent式编程 — 让AI理解你的整个项目结构，然后执行多步任务。比如“重构这个模块”、“生成单元测试”。每次Agent任务消耗1次请求额度。

安全扫描 — 自动检测代码中的安全漏洞，并提供修复建议。免费层包含基础扫描。

代码转换 — 自动升级Java版本、迁移.NET框架。免费层每月1000行额度。

AWS集成 — 回答关于AWS资源的问题，生成CLI命令，诊断控制台错误。

实际体验

代码补全质量不错，和GitHub Copilot差距不大。Agent功能在50次/月的限制下有点捉襟见肘——你用它做一次代码重构可能就耗掉好几次请求。

安全扫描实用性一般，能检测到常见漏洞，但深度不如专业安全工具。

代码转换功能对Java项目有帮助，但1000行/月的限制意味着小模块还可以，大项目不够用。

替代方案

既然新注册关了，如果你需要类似的免费编程助手，可以考虑：

  • GitHub Copilot Free — 个人开发者有限免费额度
  • Codeium — 完全免费的AI编程助手
  • Cursor Free — 有免费层
  • Amazon Q in the Cloud — 在AWS控制台里仍然免费使用（不受影响）

总结

Amazon Q Developer的免费层曾经是好东西——无限代码补全+基础Agent+安全扫描。但现在新注册已关闭，现有用户可以用到2027年4月30日。

如果你已经有账号，趁还能用赶紧用起来。如果没有，就别等了，AWS已经明确说不再接受新注册。

免费层50次Agent请求/月确实有点少，但代码补全和安全扫描是实打实的免费福利。轻度使用者够用，重度用户可能需要考虑其他方案。
