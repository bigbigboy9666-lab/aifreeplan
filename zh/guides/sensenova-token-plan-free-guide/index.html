商汤Token Plan免费攻略：1500次/5h，公测薅羊毛全指南

商汤日日新（SenseNova）的Token Plan是目前国内最强的免费API之一，每5小时给1500次调用额度，支持原生多模态模型，兼容OpenAI SDK，不需要绑卡。但免费是有条件的——商用受限、额度政策随时可能变。这篇文章把该知道的全说清楚。

一、Token Plan是什么

Token Plan是商汤科技在2026年5月8日推出的免费API公测项目，正式名称叫“Token Plan”。它属于sens senova.cn平台，跟商汤的企业训练平台SenseCore是完全分开的两套东西。

简单说：注册一个账号，生成API Key，就能免费调用商汤的大模型。免费期没有截止日期，官方只说了“公测期完全免费开放”，没承诺永久免费。

二、免费额度有多大方

先说数字：每5小时1500次调用，按滚动窗口刷新。

这意味着什么？你一天24小时不睡觉，每个5小时窗口1500次，理论上一天最多1500×4=6000次调用。实际使用肯定达不到这个数，因为你要等窗口刷新，而且不同模型之间额度是独立的。

可用模型有三个：

  • SenseNova-6.7-Flash-Lite：原生多模态，图片直接理解，不经过文字转述，Token消耗比普通模型低60%
  • SenseNova-U1-Fast：快速响应版本
  • DeepSeek-V4-Flash：DeepSeek的免费版本，编程和数学能力强

三、滚动窗口机制——最容易踩坑的地方

很多平台是按天给总量，比如“每天100次”。Token Plan不一样，它是滚动窗口。

什么意思？每过5小时，额度就重置一次。不是固定时间点重置，是每5小时滚动一次。

举个例子：你早上10点用了1500次，额度清零。然后你的窗口从10点开始算，到下午3点刷新，你又有了1500次。不管你在10点到3点之间用了多少次，窗口一到1500次就重置。

这个机制的好处是不用担心“今天用完了明天才能用”，坏处是如果你同时用多个模型，每个模型都有独立的1500次限额。

四、API密钥不会过期——但免费额度会

这是最关键的一点，也是最大的陷阱。

你生成的sk-开头API Key是永久属于你的，不会因为公测结束就作废。但是，免费调用额度是政策福利，不是绑定在你密钥上的永久权益。

什么时候变？什么时候缩？什么时候停？官方没有承诺，也没有提前通知机制。政策改动直接线上更新页面，不会发邮件也不会发公告。

网传“公测结束后会保留少量免费基础额度”——这只是第三方猜测，商汤没有官宣过这条。不要把这个当保障。

稳妥做法：个人项目可以先用免费额度开发原型，打算长期线上运行的项目，提前准备付费备选方案。

五、商用限制——别踩这条线

免费额度明确禁止大规模生产商用，仅限个人学习、Demo原型调试。

什么意思？你自己做个小工具、写个Demo、学个习，随便用。但如果你用免费额度跑了一个线上产品，每天有大量用户调用，那就踩线了。

一旦公测结束，免费额度取消之后，再调用就会报错，必须切换付费套餐。所以别在免费额度上赌长期生产环境。

六、怎么注册和获取API Key

  1. 访问sensenova.cn，注册账号
  2. 进入开发者控制台，生成API Key
  3. 用OpenAI兼容格式配置你的应用

整个过程不需要绑信用卡，不需要实名认证，手机号就能注册。

注意：官网有WAF防护，直接用curl请求会被返回403，要用浏览器或者Playwright之类的工具访问。

七、实际能做什么

Flash-Lite模型支持原生多模态，图片直接输入，不经过文字中转。这意味着你可以：

  • 上传财报PDF，让模型分析图表
  • 直接输入截图，让模型理解内容
  • 做图片相关的问答任务

官方有个案例：100页财报，模型47秒处理完。这个速度对于办公场景很有用。

另外，GitHub上有SenseNova-Skills开源项目，可以扩展更多功能。

九、什么时候该停用

以下情况建议停用免费额度，切换到付费方案：

  • 你的项目已经上线，有稳定用户使用
  • 你需要SLA保证，不能接受额度突然变化
  • 你的调用量接近免费上限，经常被限流
  • 你需要更高性能的模型

十、总结

Token Plan是目前最猛的免费API之一，每5小时1500次额度确实大方。但三点必须记住：

一、免费是限时福利，不是永久权益 二、滚动窗口机制跟按天给总量不一样，容易算错 三、商用受限，别在生产环境赌免费

建议策略：公测期间大胆用，重要的项目同时准备付费备选方案。免费薅羊毛，薅完走人，不留后患。
