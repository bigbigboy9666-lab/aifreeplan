API怎么用，和OpenAI一模一样

ChatAnywhere的API格式完全兼容OpenAI，你只需要把base_url改一下：

from openai import OpenAI

client = OpenAI(
    api_key="你的ChatAnywhere Key",
    base_url="https://api.chatanywhere.tech/v1"
)

response = client.chat.completions.create(
    model="gpt-4o",
    messages=[{"role": "user", "content": "你好"}]
)
print(response.choices[0].message.content)

国内用户用 api.chatanywhere.tech，国外用户用 api.chatanywhere.org。两个地址都能用，国内那个做了动态加速，延迟更低。

我遇到的几个坑

第一个坑：每天200次请求限制

这个限制是针对同一个IP+Key组合的。也就是说，如果你在公司用同一个WiFi，和同事各用一个Key，你们俩的请求数加起来不能超过200次/天。这个我一开始没注意，结果下午就用不了了。

解决办法：换个网络环境，或者用付费版（没这个限制）。

第二个坑：免费Key不能商用

官方文档写得很清楚：免费API Key仅限个人非商业用途，教育、非营利科研可以用，但严禁商用和大规模训练。如果你要做个产品上线，必须用付费Key。

第三个坑：高峰期可能慢

晚上8-10点是用量高峰期，响应速度会慢一些。我测过，平时1-2秒能返回，高峰期可能要5-8秒。如果对延迟敏感，建议避开这个时间段。
