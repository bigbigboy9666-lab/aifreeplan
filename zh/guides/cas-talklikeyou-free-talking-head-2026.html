TalkLikeYou 免费开源攻略：中科院自动化所实时数字人，1 步采样 32.43 FPS，4GB 显存让照片开口

中科院自动化所 MAIS 团队把 TalkLikeYou 直接开源了——给一张人像照片和一段音频，照片里的人就能开口说话，嘴部动作还能模仿指定真人的"说话习惯"。代码走 MIT 协议，模型权重全放在 HuggingFace 上，下载、推理、本地部署 0 许可费，不按次计费。

免费结论先给

  • 代码免费：GitHub 仓库 MIT 协议，可自研可商用；模型权重放 HuggingFace，一条 hf download 就能拉下来（权重本身遵循其第三方条款，见 THIRD_PARTY_NOTICES）。
  • 推理 0 平台费：跑在你自己的显卡上，无按量计费、无次数上限、无过期。一张 RTX 3090 即可，显存 < 4GB（官方流式 Demo 实测）。
  • 零门槛体验：没有高端显卡也能先用官方的 浏览器流式 Demo——对着麦克风实时驱动，RTX 3090 上 30+ FPS。
  • 推荐环境：Linux + Python 3.10 + CUDA 12.1 + cuDNN 9 + FFmpeg，官方建议显存 ≥ 12GB 跑完整推理（流式 Demo 场景 4GB 就够）。

它跟一般"照片说话"工具拉开差距的，是把"说话习惯"做成了一等公民：业内首个把个人嘴部说话习惯作为可建模对象的开源框架。你有两种入口——用官方预设编号（推荐 192 / 166 / 202）零成本切换风格，或丢一段 ≥100 帧的参考视频让它现学那个人的嘴部习惯，两种入口还能插值混合出"新习惯"。

四个能力（对应四类白嫖场景）

  • 照片开口：上传一张人像照片 + 一段音频，生成人物开口说话的视频。
  • 习惯模仿：模仿指定真人的嘴部说话习惯，预设编号或 4 秒级参考视频指定，避免"千人一面"的平均嘴。
  • 视频配音：把 --source 指向视频并加 --pose-mode source，只替换嘴部动作、保留原视频的头部动作与时序，适合多语言译制 / 出海内容口型对齐。
  • 对话数字分身：接入大模型 + 语音识别合成，做实时对话交互的数字人；官方浏览器 Demo 已支持对着麦克风实时驱动。

五分钟上手（Linux）

  1. 建环境：Linux 系统，装 Python 3.10、CUDA 12.1、cuDNN 9，确保 FFmpeg 在 PATH 里，NVIDIA 显卡显存 ≥ 12GB。
  2. 克隆代码：GitHub 主仓库 git clone，然后 conda env create -f environment.yaml 建环境（或自装 CUDA 版 PyTorch 后 pip install -r requirements.txt）。
  3. 拉权重：hf download doubi-killer/TalkLikeYou --include "checkpoints/**" --local-dir .，权重目录结构别动。
  4. 跑推理：准备一张 25 FPS 的人像照片/视频 + 一段音频，然后 python -m talklikeyou --source 照片 --audio 音频 --person-id 192 --stage0 --neutral --sampling-steps 1 --output out.mp4。想换"说话习惯"就换 --person-id，或改用 --habit-reference 参考视频。

怎么选：要"像某个人那样说话"、要低显存实时跑、要照片开口 → TalkLikeYou。要"小时级不崩、全身动作、文指令控制" → SoulX-LiveAct，但它上双卡 H100 才 20 FPS，成本高一档。

四个能直接落地的白嫖场景

  • 虚拟主播 / 直播带货：4GB 显存本地实时跑，无需真人出镜，还能复刻主播自己的说话风格。
  • 多语言视频配音：替换嘴部动作、保留原头动时序，让译制片 / 出海内容口型跟目标语言自然对齐。
  • 数字分身 / 虚拟客服：接大模型 + 语音合成做实时对话分身，用于在线客服、智能导览。
  • 个性化教学 / 培训：复刻老师 / 培训师的独特说话风格，录课程、做远程教学。

常见问题

TalkLikeYou 到底哪里免费？
代码是 MIT 协议，权重放 HuggingFace，一条 hf download 拉下来，下载 / 推理 / 本地部署 0 许可费，不按次计费、无过期。唯一的成本是你自己那张显卡（RTX 3090 显存 < 4GB 就能跑流式 Demo）。权重本身走第三方条款，商用前看一眼 THIRD_PARTY_NOTICES。
没有 12GB 大卡能不能跑？
能。官方推荐环境按 12GB 预留是为了跑完整推理链路；但浏览器流式 Demo 在 RTX 3090 上实测显存 < 4GB、30+ FPS。入门可以先在 8GB 卡上拉权重跑照片开口，长时 / 高并发再上大卡。
"说话习惯模仿"具体怎么用？
两种方式：一是 --person-id 选官方预设（192/166/202），零素材直接切风格；二是 --habit-reference 指向一段 ≥ 100 帧的真人参考视频，让它现学那个人的嘴部习惯。两种还能插值混合出"新习惯"。PLAD 指标下习惯相似度做到 0.62，高于 MimicTalk 0.48、PC-Talk 0.39。
32.43 FPS 是什么概念？
指每秒能渲染 32.43 帧说话视频，单张 RTX 3090 就能达到，满足实时 / 流式（超过 24–30 FPS 的播放门槛）。它靠一步 Flow Matching 采样实现，比走图像扩散路线的 Sonic 快近百倍，首包延迟低到可以对着麦克风实时驱动。
跟 SoulX-LiveAct 选哪个？
要"像特定的人那样说、低显存实时跑、照片开口"选 TalkLikeYou。要"小时级不崩、全身动作、文本指令控制"选 SoulX-LiveAct，但它要双卡 H100/H200 才 20 FPS，门槛高一档。前者胜在个人习惯建模 + 单卡实时，后者胜在长时稳定 + 全身控制。
