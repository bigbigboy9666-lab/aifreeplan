白嫖 / 近 0 元入口（真实存在的 4 个）

  1. 新 API 账号免费额度：Anthropic 官方明确「新用户会送一小笔免费额度试 API」（extended enterprise 试用找 sales）。首次充值/试用阶段，Haiku 5.5 短档 $0.10/$0.50 意味着这笔小钱能跑上几十万到上百万 Token 的请求量，几乎 0 成本把分类 / 路由管道跑通。
  2. 代码执行工具免费 + 每月 1,550 小时免费：只要请求里带了 web_search_20260209（或更新）/ web_fetch_20260209，代码执行调用不再单独计费；没带这两个工具时按执行时长计费，每个组织每月 1,550 小时免费，超出才计费。跑 Haiku 5.5 子智能体 + 代码执行，这块基本白送。

  4. effort 五档省钱：Haiku 5.5 首次支持按任务切 effort——简单任务用低 effort 省输出 Token 和推理成本，关键任务才拉高档。这是「同一个模型、不同价格」的省钱开关，配合 Batch 五折最狠。

避坑（从 Haiku 4.5 迁移会报错的地方）

  • budget_tokens（手动扩展思考）、temperature / top_p / top_k、assistant 消息预填，在 Haiku 5.5 上都会返回 400 错误——改用自适应思考 + effort；
  • 旧 computer_20250124 工具返回 400：Claude API / Google Cloud 改用 computer_toolset_20260801，Amazon Bedrock 用 computer_20251124；
  • 改了 system / tools / 历史轮次后再回传旧 thinking block，也会 400；
  • Amazon Bedrock 上 Haiku 5.5 暂不支持结构化输出（structured outputs），要 JSON schema 严格模式就上 Claude API 或 Google Cloud；
  • 新分词器多计约 30% Token，做成本预算时别用老模型的老用量直接套。

常见问题

Q: Haiku 5.5 有免费额度吗？
新 API 账号会送一小笔免费额度试 API（官方 FAQ 原文）。Haiku 5.5 短档 $0.10/$0.50，这笔额度能跑几十万到上百万 Token。另有代码执行工具每月 1,550 小时免费、带 web_search/web_fetch 时代码执行不单独计费。
Q: 到底多便宜？
短提示（≤10 万 Token）输入 $0.10/百万、输出 $0.50/百万；Batch 五折后约 $0.05/$0.25；缓存读 $0.01/百万。比 Sonnet 5.5（$2/$10）便宜 20 倍，比 Opus 5.5（$4/$20）便宜 40 倍。
Q: effort 五档是干嘛的？
Haiku 5.5 是 Claude 首个支持按任务切 effort 档的模型——简单任务低 effort 省成本，复杂任务拉高。官方用它实测 OSWorld、GDPval-AA、Humanity's Last Exam 三个基准在不同 effort 下的表现，是「同模型不同价」的省钱开关。
Q: 从 Haiku 4.5 迁移要注意什么？
budget_tokens、temperature、top_p、top_k、assistant 预填、旧 computer_20250124 工具、以及改 system 后回传旧 thinking 都会 400；新分词器多计约 30% Token；Bedrock 上暂不支持结构化输出。详见官方迁移指南。
Q: 能不能真 0 元？
Haiku 5.5 本身是付费 API（无 Claude 官方 :free 池）。想要 $0 长上下文/多模态，走 OpenRouter 的 Nemotron 3 等 :free 模型；想要 Claude 生态的低成本，Haiku 5.5 + Batch 五折 + 缓存 + 新账号免费额度是当前最贴 0 的组合。

总结

Haiku 5.5 的价值一句话：Claude 全家桶里单价最低（短档 $0.10/$0.50，Sonnet 的 1/20）、100 万上下文、首个 effort 五档、还能 Batch 五折 + 缓存 $0.01 + 每月 1,550 小时免费代码执行。它是执行层 / 子智能体 / 分类抽取这类高并发场景的默认选项——把重活留给 Opus，把 90% 的常规请求压到 Haiku 5.5，账单一落一大截。额度、价格、限速都在变，动手前以 Anthropic Console 实时数字为准。
