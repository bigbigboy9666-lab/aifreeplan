# MonkeyCode：奇安信出品的免费开源AI开发平台，云端编程零门槛

MonkeyCode是奇安信（中国顶级网络安全公司）推出的开源AI开发平台，完全免费。

---

## 什么是MonkeyCode

MonkeyCode是奇安信开发的AI编码平台，定位为团队级AI开发工具。

核心功能：
- **AI编码** — 内置AI模型辅助编程
- **开发环境管理** — 云端开发环境，开箱即用
- **AI任务管理** — 管理和追踪AI编程任务
- **团队协作** — 多人协作开发

---

## 免费政策

**完全免费开源** — MonkeyCode是开源项目，可以自行部署使用。

**企业版** — 奇安信也提供企业版，但个人开发者可以免费使用开源版。

---

## 怎么部署

```bash
# 克隆源码
git clone https://github.com/chaitin/MonkeyCode.git
cd MonkeyCode

# 安装依赖
npm install

# 启动
npm start
```

也可以直接使用奇安信提供的云端版本。
