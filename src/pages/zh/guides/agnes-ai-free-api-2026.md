## 接入方式

文本模型走OpenAI兼容接口，几乎所有主流框架都能直接接：

```
Base URL: https://apihub.agnes-ai.com/v1
模型名: agnes-2.0-flash
```

Python示例：
```python
from openai import OpenAI
client = OpenAI(api_key="YOUR_KEY", base_url="https://apihub.agnes-ai.com/v1")
response = client.chat.completions.create(
    model="agnes-2.0-flash",
    messages=[{"role": "user", "content": "你好"}]
)
```

图片模型走单独的接口：
```
POST https://apihub.agnes-ai.com/v1/images/generations
```

视频模型也是单独的异步接口：
```
POST https://apihub.agnes-ai.com/v1/videos/generations
```

先POST创建任务，拿到task_id，然后轮询结果。视频生成比较吃资源，排队是正常的。

## 能接入哪些工具

文本模型因为是OpenAI兼容格式，几乎所有支持自定义API的工具都能接：

- **Hermes Agent** — 配置自定义模型提供商，填API Key、Base URL和模型名
- **Claude Code / Cursor / Windsurf** — 这些编程工具都支持自定义API
- **WorkBuddy** — 可以打包成Skill，在对话里直接调用
- **n8n** — 通过HTTP请求节点调用
- **OpenClaw** — 配置为默认模型

图片模型和视频模型目前主要走API调用，或者封装成MCP工具给主模型调用。

## 注意事项

免费不代表没限制。几个需要注意的点：

**1. 没有SLA保障**
官方服务条款明确写了：免费计划不提供SLA，不保证服务可用性。高峰期可能遇到500、502、503错误。

**2. 视频生成要排队**
异步任务，创建后需要轮询。高峰期排队时间不确定，别指望即时出结果。

**3. "无限期免费"不等于"永久免费"**
历史上不少免费API后来都改了策略。阿里云之前的iFlow CLI也是"永久免费"后来停了。Agnes现在确实是免费的，但长期能不能撑住，要看平台策略和商业化节奏。

**4. 适合做原型，不适合做生产**
现阶段最适合的用法：做Demo、跑原型、批量试封面方向、给Agent接备用模型、生成内部素材。正式上线还是建议用付费方案。
