## What is MonkeyCode

MonkeyCode is an AI coding platform developed by Chaitin, positioned as a team-level AI development tool.

- **AI coding** — Built-in AI models assist programming
- **Development environment management** — Cloud dev environments, ready to use
- **AI task management** — Manage and track AI programming tasks
- **Team collaboration** — Multi-person collaborative development

## How to Deploy

```bash
# Clone source
git clone https://github.com/chaitin/MonkeyCode.git
cd MonkeyCode

# Install dependencies
npm install

# Start
npm start
```

Or use Chaitin's cloud-hosted version directly.
