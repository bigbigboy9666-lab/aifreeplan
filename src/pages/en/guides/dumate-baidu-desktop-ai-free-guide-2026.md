## What is DuMate

DuMate is Baidu Intelligent Cloud's desktop-level AI office assistant. It's not a simple chatbot — it's an AI agent that executes complex cross-application, cross-file tasks.

Core capabilities:
- **Natural language driven** — You speak, it executes
- **Cross-app collaboration** — Operates multiple applications
- **Cross-file processing** — Reads/writes various file formats
- **PPT creation** — Generate presentations in one sentence
- **Video generation** — AI-generated short videos
- **Scheduled tasks** — Automated periodic tasks
- **Data organization** — Automated data processing
