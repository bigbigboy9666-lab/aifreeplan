DuMate Free Guide: Baidu's Desktop AI Agent with 8,000 Free Credits

What is DuMate?

DuMate is Baidu's desktop-grade AI agent launched in March 2026, positioned as an "office buddy." Unlike traditional cloud-based AI tools, DuMate is a standalone desktop application that runs directly on your computer and operates your everyday software through natural language commands.

Its three core capability modules are:

  • Smart File Management: Automatic file categorization, format conversion, and key information extraction from documents
  • Multi-source Data Analysis: Data cleaning, pivot table generation, and automatic PPT creation
  • Office Automation: Automatic web form filling, OA system inspections, expense reimbursement workflows, and email processing

DuMate supports Windows and macOS platforms with one-click installation and no development environment required.

Open the DuMate desktop application and enter your needs in the chat. Examples:

DuMate will automatically open the relevant software, execute the operations, and report the results back to you.

Core Features in Detail

File Management: DuMate can read your file system and automatically categorize files based on type, size, and modification date. For common formats like PDF, Word, and Excel, it extracts key information and generates summaries. Each file analysis task costs approximately 50-200 Credits.

Data Analysis: Upload an Excel or CSV file, and DuMate automatically performs data cleaning, generates statistical charts and pivot tables. More impressively, it exports analysis results directly into a PPT presentation, eliminating manual creation. A complete data analysis plus PPT generation costs about 300-500 Credits.

Office Automation: This is DuMate's standout feature. It can simulate human operations to automatically log into various business systems (OA, expense reports, approvals) and complete data entry, status queries, and information synchronization. For example, you can have it automatically check emails every morning, organize to-do items, and generate daily reports. A single automated workflow costs about 300-500 Credits.
