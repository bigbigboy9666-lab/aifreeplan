API Usage Guide

Call Claude Opus 5 via Anthropic API:

curl https://api.anthropic.com/v1/messages \\n  --header "x-api-key: YOUR_API_KEY" \\n  --header "anthropic-version: 2023-06-01" \\n  --header "content-type: application/json" \\n  --data '{"model": "claude-opus-5", "max_tokens": 4096, "messages": [{"role": "user", "content": "Hello"}]}'

API Pricing:

  • Input: /million tokens
  • Output: 5/million tokens
