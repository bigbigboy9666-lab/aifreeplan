Claude Haiku 5.5 Free/Zero-Cost Guide: $0.10/1M input under 100k tokens, first Claude with 5-level effort control

On 2026-10-07, Anthropic shipped Claude Haiku 5.5 (model ID claude-haiku-5-5). It is not just another small model, it is the first Claude to ship with a 5-level adjustable effort control, a 1,000,000-token context, and 128,000 max output tokens. The key numbers (verified 2026-10-10 against Anthropic's pricing page and release notes): for short prompts (under 100k tokens, roughly 90% of typical requests) it costs $0.10 / 1M input and $0.50 / 1M output, which is 20x cheaper than same-generation Sonnet 5.5 ($2/$10). Stack the Batch API 50% discount, free credits for new API accounts, and 1,550 free hours of code execution per month on top, and the bill gets close to zero. Bottom line up front: if your job is classification, extraction, routing, or bulk subagent work, Haiku 5.5 is the cheapest and most cost-controllable tier in the whole Claude lineup, and it has the most near-zero-cost entry points. Here are all the measured numbers, the free entries, and the gotchas.

For the sibling tiers: Sonnet 5.5 is $2/$10, Opus 5.5 is $4/$20, Fable 5.1 is $10/$50. So Haiku 5.5's short-prompt input price is 1/20 of Sonnet's and 1/40 of Opus's. Anthropic states that prompts under 100k tokens make up about 90% of prior Haiku request volume, so most workloads land in the cheapest row. Add the 50% Batch API discount (roughly $0.05/$0.25 on the short tier) and non-realtime jobs get to near-nominal cost.

The four real zero-cost / near-zero entries

  1. Free credits for new API accounts: Anthropic's FAQ states new users get a small amount of free credits to test the API. At $0.10/$0.50 on the short tier, that grant lets you push hundreds of thousands to over a million tokens of classification / routing work for effectively nothing.
  2. Code execution tool free + 1,550 free hours/month: when your request includes web_search_20260209 (or later) / web_fetch_20260209, code-execution calls are billed only on standard token cost, no separate charge. Without those tools it bills by execution time, and each organization gets 1,550 free hours of code execution per month. Haiku 5.5 subagent + code execution is largely free in this path.
  3. Cache reads at $0.01 / 1M: keep stable system prompts and tool definitions cached; a hit is $0.01 (Sonnet 5.5 cache reads were also cut from $0.20 to $0.10 on 2026-10-07, now 0.05x base). For high-volume repeated-prefix work the effective price drops sharply.
  4. effort five tiers: Haiku 5.5 is the first model where you pick effort per task, so cheap jobs run at low effort and only critical ones run high. This is a same-model-different-price saver, and it hits hardest combined with the Batch 50%.

Getting started (from key to call)

  1. Register at console.anthropic.com and grab your API key (new accounts carry a small free credit to test the API);
  2. Set the model to claude-haiku-5-5. Minimal call: curl https://api.anthropic.com/v1/messages -H "x-api-key: ***" -H "anthropic-version: 2023-06-01" -H "content-type: application/json" -d '{"model":"claude-haiku-5-5","max_tokens":1024,"messages":[{"role":"user","content":"..."}]}'
  3. Saver trio: cache your system prompt / tools (read $0.01) + set effort per task (low for simple jobs) + use the Batch API for non-realtime (50% off);
  4. For high-volume subagents, run Haiku 5.5 as the execution layer at Build-tier 5,000 RPM and escalate only the critical decisions to Opus / Sonnet;
  5. Code execution + search: include web_search_20260209 / web_fetch_20260209 so code execution stops being billed separately.

Gotchas (migrating from Haiku 4.5)

  • budget_tokens (manual extended thinking), temperature / top_p / top_k, and assistant-message prefill all return 400 errors on Haiku 5.5; use adaptive thinking + effort instead;
  • The old computer_20250124 tool returns 400: use computer_toolset_20260801 on the Claude API / Google Cloud, or computer_20251124 on Amazon Bedrock;
  • Sending back thinking blocks after you change system / tools / earlier turns also 400s;
  • On Amazon Bedrock, Haiku 5.5 does not yet support structured outputs; if you need strict JSON-schema mode, use the Claude API or Google Cloud;
  • The new tokenizer counts about 30% more tokens, so do not reuse old-model usage for cost budgeting.

FAQ

Q: Does Haiku 5.5 have a free tier?
New API accounts receive a small amount of free credits to test the API (per Anthropic's FAQ). At $0.10/$0.50 on the short tier that grant runs hundreds of thousands to over a million tokens. Separately, code execution grants 1,550 free hours/month, and code execution is billed only on token cost when web_search / web_fetch are in the request.
Q: How cheap is it really?
For prompts under 100k tokens: $0.10/1M input, $0.50/1M output. With the 50% Batch discount it is about $0.05/$0.25; cache reads are $0.01/1M. That is 20x cheaper than Sonnet 5.5 ($2/$10) and 40x cheaper than Opus 5.5 ($4/$20).
Q: What are the five effort levels for?
Haiku 5.5 is the first Claude model where you pick effort per task, so simple jobs run cheaper at low effort and only critical ones run high. Anthropic measured OSWorld, GDPval-AA, and Humanity's Last Exam at each effort level. It is a same-model-different-price cost switch.
Q: What breaks when I migrate from Haiku 4.5?
budget_tokens, temperature, top_p, top_k, assistant prefill, the old computer_20250124 tool, and returning old thinking blocks after a system change all return 400. The new tokenizer counts ~30% more tokens, and Bedrock does not yet support structured outputs.
Q: Can I use it for real $0?
Haiku 5.5 is a paid API (there is no official Claude :free pool). For genuinely $0 long-context / multimodal, use OpenRouter's free models like Nemotron 3. For the cheapest Claude-ecosystem option, combine Haiku 5.5 with the 50% Batch discount, $0.01 cache reads, and new-account free credits.

Bottom Line

Haiku 5.5 in one sentence: the cheapest tier in the Claude lineup (short tier $0.10/$0.50, 1/20 of Sonnet), with a 1M context, the first 5-level effort control, plus a 50% Batch discount, $0.01 cache reads, and 1,550 free code-execution hours a month. It is the default choice for execution layers, subagents, and high-volume classification / extraction, keeping heavy work on Opus while pushing the 90% of routine requests to Haiku 5.5 and cutting the bill sharply. Allowances, prices, and limits are in flux, verify them in Anthropic's Console before you commit.
