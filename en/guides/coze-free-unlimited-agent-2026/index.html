Coze Free Guide: Zero-Code AI Agent Creation with Multi-Platform Publishing

Coze by ByteDance is a zero-code AI agent platform. Completely free for personal use with ~1000 daily calls. Publish to WeChat, Feishu, web and more.

What is Coze?

Coze (扣子) is ByteDance’s AI agent development platform. It allows anyone to create AI agents without coding, then publish them to multiple platforms.

Key features:

  • Zero-code — Create agents using natural language
  • Multi-platform — Publish to WeChat, Feishu, Discord, web
  • Plugin ecosystem — 1000+ plugins for extended functionality
  • Free tier — ~1000 calls daily for personal use

Free Quota Details

Daily free quota:

  • ~1000 API calls per day
  • Resets at 00:00 UTC
  • Sufficient for personal use

Features included in free tier:

  • Unlimited agent creation
  • Plugin usage
  • Multi-platform publishing
  • Basic analytics

How to Create an Agent

  1. Visit Coze — Go to coze.com
  2. Create agent — Click “Create Bot”
  3. Define personality — Set name, description, and prompt
  4. Add plugins — Choose from 1000+ available plugins
  5. Test — Chat with your agent to test
  6. Publish — Publish to desired platforms

Supported Platforms

Coze supports publishing to:

  • WeChat — WeChat Mini Program
  • Feishu — Lark/Feishu integration
  • Discord — Discord bot
  • Web — Standalone web app
  • Telegram — Telegram bot
  • Slack — Slack integration
