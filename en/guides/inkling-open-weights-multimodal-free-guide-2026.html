Inkling: Thinking Machines Lab's Open-Weights 975B Multimodal Model—Free Tinker Playground + 50% API Discount

On July 15, 2026, Thinking Machines Lab released Inkling, their first open-weights model. This 975B total parameter, 41B active-parameter multimodal Mixture-of-Experts (MoE) Transformer earned 697 points and 178 comments on Hacker News, making it the day's most-discussed AI project.

🔥 Key Highlights: Inkling is a fully free open-source model with downloadable weights. The Tinker platform offers a free Inkling Playground (with agentic web search), and Tinker API currently has a 50% limited-time discount.

1. Technical Specifications

Core Parameters

  • Total Parameters: 975B (billion)
  • Active Parameters: 41B (activated per inference)
  • Architecture: Mixture-of-Experts Transformer (following DeepSeek-V3 design patterns)
  • Expert Structure: 256 routed experts + 2 shared experts per MoE layer, 6 routed experts activated per token
  • Context Window: Up to 1M tokens (64K and 256K options available)
  • Pre-training Data: 45 trillion tokens (text, images, audio, and video—multimodal)
  • Optimizer: Muon (for large matrix weights) + Adam (for other parameters)

Model Family

Alongside the full Inkling model, Thinking Machines Lab also released Inkling-Small:

  • Inkling-Small: 12B active parameters—significantly lower cost and latency
  • Performs close to full Inkling on reasoning and agentic tasks
  • Ideal for coding, LLM grading, and synthetic data generation where cost and latency matter

Multimodal Capabilities

Inkling natively reasons over three modalities without separate adapters:

  • Text: General language understanding and generation
  • Images: Visual understanding and analysis (encoder-free architecture)
  • Audio: Native audio processing (inputs as dMel spectrograms)
💡 Why It Matters: Most multimodal models require separate vision and audio encoders. Inkling uses an encoder-free architecture where all three modalities are trained jointly, reducing inference complexity and latency.

4. Key Features of Inkling

Controllable Thinking Effort

Inkling's unique design lets users control the model's "thinking depth." From low-effort to high-effort, the model balances cost and performance flexibly. This is valuable for scenarios where you need to adjust response quality based on budget constraints.

Native Agentic Capabilities

Inkling is purpose-built for agent and coding workflows:

  • Built-in tool calling and function execution
  • Long-horizon multi-step task planning
  • Integration with various coding and agent harnesses
  • Randomized tool-set training reduces sensitivity to specific tools

Self-Fine-Tuning Demo

Thinking Machines Lab demonstrated Inkling fine-tuning itself—the model wrote its own fine-tuning job, ran it on Tinker, and evaluated the results. This showcases Inkling's powerful agentic coding abilities.

6. FAQ

❓ What license does Inkling use?

Inkling is released under an open-source license with fully free weights for research and commercial use. Refer to Thinking Machines Lab's official announcement for specific license terms.

❓ How do I use Inkling without high-end GPUs?

The simplest way is through the Tinker Playground—completely free with no hardware requirements. For API access, Tinker offers a 50% limited-time discount.

❓ What's the difference between Inkling-Small and the full version?

Inkling-Small has only 12B active parameters (vs. 41B for full Inkling) with a similar training recipe and architecture. It performs close to the full model on reasoning and agentic tasks but with significantly lower cost and latency, ideal for latency-sensitive scenarios.

❓ How long is the Tinker Playground free trial?

Thinking Machines Lab has announced the Inkling Playground is free for a limited time, but no specific end date has been announced. We recommend signing up early.

❓ Which inference frameworks does Inkling support?

It supports SGLang, vLLM, TokenSpeed, Unsloth, and Hugging Face among others. Self-hosting requires configuring dependencies yourself.
