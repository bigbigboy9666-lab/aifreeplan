OpenBMB VoxCPM2 Free TTS Guide: Apache-2.0 at Zero Cost, 30 Languages + 48kHz Studio Audio on an 8GB GPU

OpenBMB has open-sourced VoxCPM2, a 2B-parameter text-to-speech model. Weights + code are fully open under Apache-2.0, commercial-ready. Key figures (verified 2026-10-06 against the official GitHub README and the AI-tools-set entry): trained on 2.36M hours of multilingual speech, covers 30 languages + 9 Chinese dialects (Cantonese, Northeast, Sichuan, etc. — you feed in any supported language and it synthesizes directly, no language tag), outputs 48kHz studio audio (16kHz in, 48kHz out via built-in super-resolution), with RTF 0.30 (RTX 4090 standard) / 0.13 (Nano-vLLM accelerated) and first-chunk latency ~150ms / ~80ms. The deployment bar is low: Python 3.10 + PyTorch 2.5 + CUDA 12.0, ~8GB VRAM, ~4GB model download, and it starts with a single pip install voxcpm. The free conclusion up front: the license is $0 (Apache-2.0, commercial use included), and inference costs only your own GPU — no per-token billing, no daily quota, no expiration. If you have no GPU, the official HuggingFace online demo (OpenBMB/VoxCPM-Demo) is free to try Voice Design and cloning. Below are all the verified numbers, deploy steps, four use cases, and an open-source head-to-head.

Four capabilities (what separates it from CosyVoice3 / Fish S2): Voice Design creates a brand-new voice from a single text description (e.g. "a gentle middle-aged woman, slightly husky"), no reference audio needed — the official "first-of-its-kind"; Controllable Cloning keeps the reference timbre while adjusting emotion / speed via text tags; Ultimate Cloning takes reference audio + its transcript for continuation-style replication down to breath and rhythm; Real-Time Streaming emits audio in chunks with 80ms first-chunk.

How to Deploy for $0 (install to first sound)

  1. Prepare the runtime: Python 3.10+ / PyTorch 2.5+ / CUDA 12.0+, leave ~8GB VRAM free;
  2. Install: pip install voxcpm (first run auto-downloads ~4GB of model weights);
  3. Make it talk from the CLI (no code needed):
    voxcpm design "gentle middle-aged woman, slow pace" -t "Welcome" -o out.wav
    voxcpm clone ref.wav -t "Hello" -o clone.wav (pair VoxCPM2-BaseLM-Q8_0.gguf + VoxCPM2-Acoustic-F16.gguf);
  4. Browser UI: run the project's app.py for a Gradio web interface;
  5. Production throughput: install nano-vllm-voxcpm, RTF drops to 0.13 and it handles concurrency;
  6. No GPU? Use the free HF online demo, zero install.

Four $0 Use Cases (Pick by Scenario)

  1. Multilingual dubbing: 30 languages + 9 dialects; one Chinese script straight out in Cantonese / Sichuan / Japanese / English — courseware, short video, overseas content, no cast needed;
  2. Audiobook / podcast at scale: design one host voice with Voice Design, freeze the timbre with a LoRA on 5–10 min of audio, then synthesize infinitely — marginal cost ≈ 0;
  3. Voice agents / hardware: RTF 0.13 + 80ms first-chunk make live streaming viable; self-hosting means no data leaves your infra and no metered bill;
  4. Game / VTuber localization: Ultimate Cloning replicates a character's original voice detail, keeps timbre consistent across shots, and drives 40+ distinct expressions in real time.

FAQ

Q: Is VoxCPM2 really free?
The Apache-2.0 license is $0, including commercial use (open weights + code). Inference only costs your own 8GB GPU — no platform billing, no request cap, no expiry. No GPU? The free HF online demo covers it.
Q: How strong a GPU do I need?
About 8GB VRAM to start (RTX 3060/4070, A10 class), ~4GB model download. A $0.1–0.5/hr cloud GPU instance works too; add nano-vllm-voxcpm in production to push RTF to 0.13.
Q: What does 48kHz mean, and is it worth it?
It is the output sample rate — 16kHz reference in, 48kHz studio-grade out via built-in super-resolution, far above the 16/24kHz of typical TTS. It matters for audiobooks, brand voice, and ADR (voice-over repair); for chat / customer service 16kHz is plenty.
Q: How is Voice Design different from cloning?
Voice Design needs no reference audio — a single text description invents a voice from scratch (the official "first-of-kind"). Cloning needs a reference audio; controllable cloning keeps the timbre while text tags adjust emotion / speed, and ultimate cloning adds a transcript for continuation-style replication.
Q: VoxCPM2 vs CosyVoice3 vs Fish Audio — which?
Pick VoxCPM2 for top 48kHz audio + text-to-voice; Fish S2 for language breadth (80+); CosyVoice3 when you only have 4–6GB VRAM and want Chinese emotion instructions. All three are $0 to self-host; the difference is quality / languages / cloning depth.
