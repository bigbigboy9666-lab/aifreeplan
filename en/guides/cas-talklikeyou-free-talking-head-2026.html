TalkLikeYou Free Open-Source Guide: CAS Real-Time Talking Head — 1-Step Sampling at 32.43 FPS, Talks from a Photo on 4GB VRAM

MAIS at the Institute of Automation, Chinese Academy of Sciences has open-sourced TalkLikeYou. Give it one portrait photo and one audio clip and the person in the photo starts talking, with lip motion that can imitate a specific real person's speaking habits. The code is MIT-licensed and every model weight is on HuggingFace: downloading, inference, and self-hosting all cost $0 in licensing — no per-call billing.

The free verdict, up front

  • Free code: the GitHub repo is MIT-licensed, so you can build and ship commercial products on top of it. Model weights live on HuggingFace and pull down in one hf download (the weights themselves follow their third-party terms — see THIRD_PARTY_NOTICES).
  • Zero platform fee: it runs on your own GPU — no metered billing, no request cap, no expiry. A single RTX 3090 is enough; the official streaming demo holds < 4GB of VRAM.
  • Zero-barrier trial: no big GPU? Start with the official browser streaming demo — real-time, mic-driven, 30+ FPS on an RTX 3090.
  • Recommended stack: Linux + Python 3.10 + CUDA 12.1 + cuDNN 9 + FFmpeg, with ≥ 12GB VRAM recommended for the full inference path (the streaming demo scenario is fine at 4GB).

What separates it from the usual "make a photo talk" tools is that it treats "speaking habit" as a first-class citizen: it is the first open framework that models an individual's lip-speaking habits as a designable object. You have two entry points — a preset habit ID (recommended 192 / 166 / 202) to switch styles at zero cost, or a ≥100-frame reference video so it learns that person's habits on the fly. The two can be blended by interpolation to mint a "new" habit.

Four capabilities (four ways to ride it for free)

  • Photo talks: drop in a portrait photo + one audio clip, get a video of the person speaking.
  • Habit imitation: imitate a specific person's lip habits via a preset ID or a short reference video, escaping the "average mouth" of everyone else.
  • Video dubbing: point --source at a video and add --pose-mode source to swap only the lip motion while preserving the original head motion and timing — great for multilingual localization and cross-border content.
  • Conversational avatar: wire up an LLM + ASR/TTS for a real-time, interactive digital twin; the official browser demo already drives off a live microphone.

Five-minute start (Linux)

  1. Set up the env: on Linux, install Python 3.10, CUDA 12.1, cuDNN 9, make sure FFmpeg is on PATH, and use an NVIDIA GPU with ≥ 12GB VRAM.
  2. Clone the code: GitHub main repo, git clone, then conda env create -f environment.yaml (or install a CUDA PyTorch build and pip install -r requirements.txt).
  3. Pull the weights: hf download doubi-killer/TalkLikeYou --include "checkpoints/**" --local-dir .; keep the checkpoint directory layout intact.
  4. Run inference: prepare one 25 FPS portrait photo/video plus an audio clip, then python -m talklikeyou --source photo --audio audio --person-id 192 --stage0 --neutral --sampling-steps 1 --output out.mp4. To change the "speaking habit," swap --person-id, or switch to --habit-reference reference-video.

FAQ

Where exactly is TalkLikeYou free?
The code is MIT and the weights are on HuggingFace — one hf download, $0 in licensing for downloading, inference, and self-hosting, with no per-call billing and no expiry. Your only cost is the GPU itself (an RTX 3090 holds the streaming demo under 4GB). The weights follow their third-party terms, so glance at THIRD_PARTY_NOTICES before commercial use.
Can I run it without a 12GB card?
Yes. The recommended 12GB reservation is for the full inference path; the browser streaming demo runs under 4GB at 30+ FPS on an RTX 3090. Start on an 8GB card for photo-to-speech and scale up for long or high-concurrency workloads.
How do I actually use "speaking-habit imitation"?
Two ways: --person-id picks an official preset (192/166/202) with zero assets, or --habit-reference points at a ≥ 100-frame real-person reference video so it learns that person's habits on the fly. Both can be interpolated into a "new" habit. Under the PLAD metric the habit similarity reaches 0.62, ahead of MimicTalk's 0.48 and PC-Talk's 0.39.
What does 32.43 FPS mean in practice?
It renders 32.43 frames of talking video per second on a single RTX 3090, clearing the 24-30 FPS real-time bar. One-step Flow Matching gets there, ~100x faster than the image-diffusion route (Sonic), with low first-chunk latency so it can drive off a live microphone.
TalkLikeYou or SoulX-LiveAct?
Pick TalkLikeYou to "talk like a specific person," stay low-VRAM and real-time, and do photo-to-speech. Pick SoulX-LiveAct for hour-level stability, full-body motion, and text-instruction control — but it needs dual H100/H200 for 20 FPS, a higher bar. TalkLikeYou wins on habit modeling + single-card real-time; SoulX-LiveAct wins on long-horizon stability + full-body control.
