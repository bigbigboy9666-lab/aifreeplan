# Bonsai 27B: Complete Guide to Running a 27B-Class AI Model Free on Your Phone - Based on Qwen3.6, Apache 2.0 Licensed

Bonsai 27B is a low-bit quantized version of Qwen3.6-27B by PrismML, runnable on phones and laptops, Apache 2.0 licensed free.

---

## What is Bonsai 27B

Bonsai 27B by PrismML is a low-bit quantized version of Qwen3.6-27B, not a newly trained model.

Key features:
- **Based on Qwen3.6** — Same architecture, just quantized
- **5.9GB** — Extremely small model file
- **Apache 2.0** — Completely free for commercial use
- **Runs on phones** — 27B model on smartphones

---

## How to Run

**Option 1: On phone**
- Download PrismML's mobile inference engine
- Install Bonsai 27B model
- Run directly

**Option 2: On laptop**
- Needs 8GB+ RAM
- Use llama.cpp or similar engine
- Model file only 5.9GB

**Option 3: On server**
- Needs 14GB+ VRAM GPU
- Better performance
