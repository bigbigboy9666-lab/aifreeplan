Ego Lite 免费攻略：Citro Labs 专为 AI Agent 设计的 Chromium 浏览器

2026年7月初，Citro Labs 发布了 Ego Lite —— 一款专为 AI Agent（人工智能智能体）设计的 Chromium 浏览器。与传统浏览器自动化工具（如 Playwright、Puppeteer）不同，Ego Lite 解决了登录态丢失、资源占用过高、干扰用户正常浏览等核心痛点，实现了人类用户与 AI Agent 的真正协同工作。

什么是 Ego Lite？

Ego Lite 是一个基于 Chromium 内核的独立浏览器应用，同时在 CLI 层面暴露了完整的 Node.js 运行时。它的核心设计理念是：让 AI Agent 在独立的任务空间（Task Space）中静默驱动浏览器，执行页面读取、点击、API 探测、截图验证等操作，同时继承用户登录态且不干扰正常浏览窗口。

简单来说，你可以在日常使用中正常打开 Chrome 浏览网页，同时让 AI Agent 通过 Ego Lite 在后台独立完成需要登录态的自动化任务——比如登录你的邮箱抓取数据、操作内部系统、爬取需要认证的页面等。

核心特性一览

1. Task Space 隔离

每个任务空间是独立的浏览上下文，拥有专属标签页，默认继承当前用户的 Cookie 与登录态。Agent 可在需要登录的站点内操作，不会抢占用户正在使用的浏览器窗口控制权。这意味着你可以一边开会一边让 Agent 自动整理邮件。

2. 一键迁移 Chrome 数据

安装 Ego Lite 后可以一键迁移 Chrome 的书签、扩展、Cookie 和登录态。无需重新配置，开箱即用。

3. 多模态操作能力

Ego Lite 提供三种互补的操作方式：

  • 语义快照（Semantic Snapshot）：提取页面可交互元素的语义信息（文本、按钮、链接），适合标准网页结构
  • 视觉工作流（Visual Workflow）：当 DOM 与真实界面不一致时（如 Canvas、SVG、地图），退回到截图 + 坐标 + 键盘动作验证
  • Chrome DevTools Protocol（CDP）：直接调用底层协议，读取前端状态、探测隐藏 API 接口、解析前端 bundle

4. 精确的页面操作

通过语义化结构，Agent 可以精准点击按钮、填写表单、执行 JavaScript 直接读取 DOM 状态，甚至发起或拦截浏览器内部请求获取前端真实 API 返回数据。

免费使用方式

Ego Lite 完全免费开源，有两种主要使用方式：

方式一：直接下载安装（推荐新手）

访问 Ego Lite 官网 下载安装包，安装后一键迁移 Chrome 数据。这是最简单的入门方式，适合大多数用户。

方式二：通过 MCP 技能包集成（推荐开发者）

如果你使用 Claude Desktop、Cursor 或其他支持 MCP 的 AI 工具，可以通过以下命令安装 Ego Lite 的技能包：

npx skills add citrolabs/ego-lite

安装完成后重启 Agent，确保技能包被正确加载。之后只需在对话中输入 browse 开头的指令，描述需要浏览的网页与操作目标即可。
