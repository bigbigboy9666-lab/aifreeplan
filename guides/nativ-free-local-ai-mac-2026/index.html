Nativ 免费本地 AI 桌面应用：Apple Silicon 上运行开源模型，零订阅零云端零账户

Nativ 是一款 100% 开源、MIT 许可的 macOS 原生 AI 应用，专为 Apple Silicon 设计。基于 MLX 框架，可在本地运行前沿开源模型，支持聊天、代码补全、语音转录等多种模态。完全免费，无需注册账户、无需订阅、无需云端连接。

什么是 Nativ

Nativ 是一个基于 SwiftUI 开发的 macOS 原生应用，底层使用 MLX-VLM（Meta 的 MLX 推理框架）作为推理引擎。它不仅仅是一个聊天界面，而是一个完整的本地 AI 工作区。

核心功能：

  • 本地聊天与视觉 — 流式对话响应、图片附件、推理输出
  • 模型库管理 — 发现已安装的 MLX 模型、一键下载、切换模型
  • 性能分析面板 — 追踪请求量、Token 用量、首字延迟
  • 本地 API 服务器 — OpenAI 兼容的 /v1/chat/completions 端点
  • 编码工具集成 — Codex、Claude Code、Pi、Hermes、OpenCode
  • 菜单栏控制 — 启动/停止服务器、切换模型、查看统计

安装指南

方法一：直接下载（推荐）

  1. 访问 Nativ GitHub Releases 页面
  2. 下载最新版的 Nativ-*.dmg 文件（约 342 MB）
  3. 将 Nativ 拖入 Applications 文件夹
  4. 首次启动时选择已安装的模型或继续按需加载

方法二：从源码编译

brew install xcodegen
make xcode-generate
make xcode-build
open build/XcodeDerivedData/Build/Products/Debug/Nativ.app
