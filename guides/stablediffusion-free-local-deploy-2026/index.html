本地部署方式

方式1：Automatic1111 WebUI（推荐新手）

git clone https://github.com/AUTOMATIC1111/stable-diffusion-webui.git
cd stable-diffusion-webui
./webui.sh

方式2：ComfyUI（推荐高级用户）

git clone https://github.com/comfyanonymous/ComfyUI.git
cd ComfyUI
python main.py

方式3：Fooocus（最简单）

  • 一键安装包，适合新手
  • 下载地址：github.com/lllyasviel/Fooocus

硬件要求

  • GPU：NVIDIA显卡，8GB+显存（推荐12GB+）
  • 内存：16GB+
  • 硬盘：50GB+（存放模型文件）

没有GPU也可以用CPU运行，但速度慢很多。

社区模型

Stable Diffusion的强大之处在于丰富的社区模型：

  • Civitai — 最大的社区模型库
  • HuggingFace — 官方模型库
  • LiblibAI — 国内最大的模型社区

下载社区模型后放入models文件夹即可使用。
